Setup Apps Script (sekali, atau setiap kode diubah)

1) Buka Sheet → Extensions → Apps Script. Ganti semua kode dengan isi file Code.gs, lalu Save.
2) Deploy → Manage deployments → ✏️ → Version: New version → Deploy. Pakai URL yang sama; kalau URL berubah, tempel di kolom Apps Script di atas.
3) Type: Web app · Execute as: Me · Who has access: Anyone. Setujui izin akses jika diminta.
4) Tes: klik “Tes koneksi”, atau buka URL /exec di tab baru. Harus muncul teks JSON, bukan halaman login.
